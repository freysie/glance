Stream a macOS screen region to the (local) web.

[demo video goes here]

## Usage

- Open Glance, accept screen sharing permissions
- Select a screen region to stream — URL is copied to clipboard
- Paste URL into a browser and watch the stream

## Features

- Local WebRTC streaming
- H.264 profile negotiation
- Support for multiple displays
- Crisp text

## Roadmap

- Stream over the internet
- Audio streaming
