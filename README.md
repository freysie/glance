## Usage

- Open Glance, allow screen recording
- Select a region to stream — the URL is copied to your clipboard
- Paste the URL into a browser to view the stream

## Features

- Local WebRTC streaming
- H.264 profile negotiation
- Crisp text

## Roadmap

- Stream over the internet
